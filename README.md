# 🩺 Diabetic Retinopathy Detection using Deep Learning & AI Chatbot

This project is a web-based application that detects the severity of **Diabetic Retinopathy** from retinal images using a **CNN model** and provides medical guidance using an **AI-powered chatbot (Google Gemini)**.

---

## 🚀 Features
- Upload retinal image and predict DR severity
- CNN-based image classification
- Severity visualization using bar graph
- Precautionary medical tips for each stage
- AI chatbot for user queries
- User-friendly Flask web interface

---

## 🧠 Classes Predicted
- No_DR
- Mild
- Moderate
- Severe
- Proliferative_DR

---

## 🛠️ Tech Stack

- Flask
- TensorFlow / Keras
- NumPy
